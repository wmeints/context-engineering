# Context Engineering

This project helps developers to get started building software using a spec-driven
approach with the help of coding agents. This project has two parts to it:

- Ready-made configurations for different kinds of software projects.
- A set of documentation to explain the principles, the base approach, and how to extend the approach.

## Project structure

- `docs` - contains the documentation explaining the principles, approach, and extension points.
- `examples` - contains sample project structures for different kinds of projects.

## Working with the project

- Use `uv sync` to download the dependencies for the project
- Use `uv run mkdocs build` to build the project documentation
